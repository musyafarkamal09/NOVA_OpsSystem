# Arsip: snapshot frontend lama

Salinan lama dari folder `img/frontend/` (paket "Frontend Refresh"). **Tidak dipakai** oleh aplikasi saat ini
dan tidak dirujuk oleh berkas mana pun di repo; disimpan hanya sebagai referensi.

Hanya berkas yang **berbeda** dari versi aktif yang disimpan di sini. Berkas yang identik byte-per-byte
dengan versi aktif (gambar, `nav-back.js`, `notify.js`, `appsscript.json`, dokumen) tidak disalin ulang.

Aman dihapus bila tidak diperlukan (riwayat tetap ada di Git).
